   "A/B 실험의 B 로 취급하지 않는다"고 했으므로, 같은 디렉터리에 두면
   나중에 섞일 위험이 있어 `data/labels_calb_probe/` 로 갈랐습니다.

2. **`build_labels_B.py` 에 인자 둘을 더했습니다** (`--out` · `--calb-xlsx`).
   스크립트를 복제하는 대신 매개변수화했습니다. 기본값은 그대로라 기존
   호출은 영향받지 않습니다 `[확인]`.

3. **`paper` 슬롯을 미조사로 두었습니다.** 지시는 "두 논문 표로 확인
   가능"이라 했지만 **제가 확인하지 못했습니다.** `확인` 으로 적으면 제가
   보지 않은 것을 보았다고 기록하는 셈이라 `미조사` + `searched` 로
   남겼습니다. 사람이 논문을 보고 채우면 바로 닫힙니다.

4. **"13개 하위 데이터셋" 을 검증하지 못했습니다.** 코드 분할로 세면
   12개입니다(§3-2). 묶음 기준이 달라서인지 논문 진술이 다른 것인지
   가리지 못해 `[미확인]` 으로 남겼습니다.

5. **`run.py check` 를 깨진 채로 두었습니다.** 3번을 하면 필연이고
   `LOCK.md` 수정이 금지되어 있습니다. 새 해시를 §3-3 에 적었습니다.

6. **이전 `label_ab_cellwise.json` 을 덮어썼습니다.** 집계값이 같고
   (재현 40/40) 원자료가 추가된 상위 집합이라 되돌릴 이유가 없습니다.
   이전 판은 세션 스크래치패드에 백업해 두었습니다.
