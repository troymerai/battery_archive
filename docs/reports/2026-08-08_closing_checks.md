### 2-2. **`γ⁺`·`γ⁻` 는 학습 분할에서 계산되지 않습니다 — 하드코딩입니다**

```python

preprocess_MICH.py:24     THRESHOLD_DECREASE = -1.7  # (1st percentile: -4.78%, conservative)
preprocess_MICH_EXP.py:20 THRESHOLD_INCREASE = 0.5   # (99th percentile: 0.44%)
```

> `[확인]` **MICH 는 주석이 1 백분위를 −4.78% 라고 적어 놓고 값은 −1.7 을
