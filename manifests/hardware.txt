# 1. torch  논문 고정값 2.4.1 은 sm_120 을 지원하지 않아 5080 에서 못 씁니다.

#    **재설치하지 마십시오** — requirements 를 그대로 깔면 accelerate 의
#    torch>=1.10.0 해석으로 2.4.1(비 cu128)로 되돌아갑니다. docs/RUN.md 1-1.
#
# 2. deepspeed  제외했습니다. Windows 에 휠이 없고 nvcc 도 MSVC 도 없어
#    소스 빌드가 불가합니다. 원본은 ZeRO stage-2 로 돌고 이 기계는
#    accelerate 기본 경로로 돕니다 — 같은 조건이 아닙니다.
#
# 3. GPU 1장  논문은 2장(--multi_gpu, num_process=2)입니다. 배치는
#    문서값 x 2 를 한 프로세스에 주어 실효 배치를 맞췄습니다.
#
# 4. num_workers 0  Windows 는 워커마다 프로세스를 통째 복제합니다.
#    물리 RAM 15.1 GiB 로는 감당되지 않습니다.

# --- 가상 메모리 ---
