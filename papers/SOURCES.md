## PDF 를 커밋하지 않는 이유

`.gitignore` 에 `papers/*.pdf` 가 들어 있습니다.

arXiv 프리프린트와 ACM 게재본은 라이선스가 각기 다릅니다. arXiv 는 논문마다
저자가 고른 라이선스(arXiv perpetual license · CC BY · CC BY-NC-ND 등)가
붙고, ACM 게재본은 별도 저작권 정책을 따릅니다. **재배포 가능 여부가
논문마다 다르고 확인되지 않았으므로** 저장소에 담지 않습니다.

> **저장소를 프라이빗으로 유지하고 랩 내부에서만 쓴다면 `.gitignore` 의
> `papers/*.pdf` 줄을 지워도 됩니다.** 그 경우 조원이 각자 받지 않아도 되고
> 판본이 갈릴 일도 없습니다. 공개로 전환할 때 반드시 되돌리십시오.

판단은 저장소를 공개할지 여부에 달려 있습니다. 지금은 안전한 쪽(제외)입니다.

## 무엇을 읽는가

논문은 **정답지가 아니라 비교 대상**입니다. "논문이 이렇게 썼으니 코드가
틀렸다" 도, 그 반대도 아닙니다. 갈리는 지점을 짚어 `findings/registry.yaml`
의 `paper` 슬롯을 채우는 것이 목적입니다.

읽으며 훑을 곳:

| 위치 | 뽑을 것 |
|---|---|
| Abstract | 통합 데이터셋 수, 배터리 수, 배수 주장 |
| **Table 1** | 서브셋별 배터리 수 · 포맷 · 화학계 · 온도 · 프로토콜 · 출처 · 연도. `META-` 목록의 뼈대 |
| 데이터 구성 절 | 4도메인 분할 기준, λ 설정 |
| 식 (1)~ | 모든 수식의 정의와 기호 |
| 평가 절 | MAPE · 15%-Acc 정의, 분할 방식 |
| Figure 캡션 | 축 정의, 사이클 범위 |
| **부록 A** | 전처리 상세, 서브셋별 소개, 자체 3개 데이터셋 시험 조건 |

**부록을 반드시 보십시오.** 본문에서 빠진 것이 부록에 있습니다. 외삽 규칙과
Zn-ion 공칭용량 정의가 그 사례입니다.

### 순서 — 데이터 먼저, 논문 나중

`META-` 계열(화학계 59종, 포맷 8종, 프로토콜 421종 …)은 **재집계를 먼저
하고 논문을 나중에** 봅니다.

```
1. 배포 데이터 재집계     notebooks/01_pkl_structure.ipynb
2. 논문 숫자와 대조       Table 1 · Abstract · 부록 A
3. 갈리는 것만 레코드화   META- 목록은 여기서 확정된다
4. 논문 근거 찾기         부록까지. 못 찾으면 `조사했으나불명`
```

순서를 뒤집으면 항목이 폭발하고, 무엇을 찾아야 하는지 모른 채 논문을 읽게
됩니다.

## 슬롯이 나뉘어 있어 분담이 됩니다

논문 담당이 `paper` 슬롯만 채우고 다른 사람이 `code` 슬롯만 채워도 판정이
나옵니다. 결론을 서로 조율할 필요가 없습니다. 판정은 `render.py` 가 슬롯에서
유도합니다.

`paper` 슬롯을 채울 때 지켜야 할 것 하나 — **`미조사` 를 `조사했으나불명`
으로 말하지 마십시오.** 안 찾아본 것과 찾아봤는데 없는 것은 다릅니다.
`부재확인` 과 `조사했으나불명` 은 `searched` 에 **어디를 봤는지** 를 적어야
성립합니다. `findings/SCHEMA.md` 를 보십시오.
